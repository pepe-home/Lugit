# PRD — metro

## 产品目标

- 要达成的目标：用一份可编辑的线网数据，一站一站地产出贴近真实车站的印刷与点阵物料（站名牌、线路牌、报幕机），并可直接导出分享。

## 用户与使用场景

- 目标用户：制作地铁实景车辆 / 车站模拟物料的爱好者；为 Hmmsim、BVE 等模拟器准备素材的作者；想复刻某条真实线路导视的爱好者。
- 典型场景：
  - 选定合肥 1 号线的「包公园」，开往九联圩方向，生成该站的站名牌、线路牌与报幕机画面，导出 PNG / SVG 用于视频或印刷。
  - 在「线网」工作区调整某条线的站序、增删或改名站点，再回到「车站」逐站产出物料。
  - 为整条线路导出全部站点的报站文本，交给 TTS 批量合成语音。

## 核心问题

- 要解决的关键问题：现有工具里物料与呈现强耦合（单线、单风格参数写死），报站屏另立门户，且中文报站的措辞、换乘、终点站提示都要手工维护；本产品把「哪一站、哪一方向」作为唯一输入，其余信息由线网推导。

## 功能及其意义

| 功能                         | 解决什么                | 为什么需要                                     |
| ---------------------------- | ----------------------- | ---------------------------------------------- |
| 线网编辑（线路、站名、站序） | 自建或调整线网          | 物料内容全部来自线网；换乘由站点归属自动推导   |
| 站名牌（印刷品）             | 站台 / 墙面的站名与去向 | 线路名称、站名、当前方向的终点站三件事一牌说清 |
| 线路牌（印刷品）             | 单行展示全线站点        | 已过节点置灰、未到节点用线色，当前站高亮       |
| 报幕机（单行点阵屏）         | 车载报站画面            | 低分辨率点阵滚动显示一句报站，随场景变化       |
| 逐站切换视角                 | 批量制作                | 使「一站一物料」的制作流程成立                 |
| 导出 PNG / SVG、整线播报文本 | 交付成果                | 物料要能用于视频、印刷与语音合成               |

## 功能之间的关系

- 线网数据是唯一事实源；三种物料都从「当前线网 + 视角」派生，任意视角或线网改动会同时反映到全部物料。
- 线网工作区的「线路示意」与车站工作区的「线路牌」共享同一套站序与方向语义，但前者用于编辑校验，后者是交付物料。
- 整线播报文本由报幕机使用的同一套模板生成，保证画面与文本一致。

## 范围与非目标

- 范围内：合肥轨道风格的站名牌、线路牌、报幕机；站点级线网编辑（增删站、调序、改名、改线色）；逐站查看与导出；导入 rmg 项目文件的数据能力。
- 范围外：地图底图与拖放绘制线网、语音合成、账号与云存储、其他城市风格（数据层已为多城市留出 `Network` 抽象，但尚未提供）；合肥官方车站编号（公开资料中没有该体系）。
