# PRD — metro

## 产品目标

- 要达成的目标：用一份线网数据，一站一站地产出贴近真实车站的信息物料（站牌、路线图、报站屏），并可直接导出分享。

## 用户与使用场景

- 目标用户：制作地铁实景车辆 / 车站模拟物料的爱好者；为 Hmmsim、BVE 等模拟器准备素材的作者；想复刻某条真实线路导视的爱好者。
- 典型场景：
  - 选定合肥 1 号线的「包公园」，向右行车，生成当前站名牌、终点站站牌（九联圩）和路线图，导出 PNG 用于视频或课件。
  - 为整条线路导出全部站点的报站文本，交给 TTS 批量合成语音。

## 核心问题

- 要解决的关键问题：现有工具里物料与呈现强耦合（单线、单风格参数写死），放送机另立门户，且中文报站的措辞、换乘、终点站提示都要手工维护；本产品把「哪一站、哪一方向」作为唯一输入，其余信息由线网推导。

## 功能及其意义

| 功能                              | 解决什么              | 为什么需要                                                 |
| --------------------------------- | --------------------- | ---------------------------------------------------------- |
| 线网数据（9 线、204 站、20 换乘） | 免去逐线录入          | 物料内容全部来自线网；换乘、终点站、站序由数据推导         |
| 终点站站牌（LED / 印刷两种样式）  | 车外去向显示          | 最常见的一类物料，LED 样式要求点阵与滚动                   |
| 当前站名牌                        | 车门上方屏            | 与终点站牌、路线图共享下一站与换乘信息                     |
| 路线图                            | 站台与车内的横向条图  | 需要当前站高亮、已过站置灰、换乘徽标                       |
| 放送机                            | 车载 LED 点阵报站画面 | 报站文案随场景（离站 / 到站 × 是否终点站）变化，过长需滚动 |
| 逐站切换视角                      | 批量制作              | 使「一站一到站」的制作流程成立                             |
| 导出 PNG / SVG、整线播报文本      | 交付成果              | 物料要能用于视频、印刷与语音合成                           |

## 功能之间的关系

- 线网数据是唯一事实源；四类物料都从「当前线网 + 视角」派生，任意视角改动会同时反映到全部物料。
- 放送机与终点站牌共享 LED 屏渲染与滚动规则；当前站名牌与路线图共享站名排版与换乘徽标。
- 整线播报文本由放送机使用的同一套模板生成，保证画面与文本一致。

## 范围与非目标

- 范围内：合肥轨道风格的上述四类物料、逐站查看与导出、导入 rmg 项目文件的数据能力。
- 范围外：地图底图与线网编辑界面、语音合成、账号与云存储、其他城市风格（数据层已为多城市留出 `Network` 抽象，但尚未提供）；合肥官方车站编号（公开资料中没有该体系）。
