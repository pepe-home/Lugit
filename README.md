# metro

合肥轨道风格的线网与车站物料制作工具：在真实地图上编辑线网，在车站工作区一站一站地产出站名牌、线路牌与报幕机。

## 这是什么？

- 定位：面向地铁爱好者的**线网编辑 + 物料制作**工具，不依赖服务端，打开网页即可创作与导出。
- 解决的核心问题：地铁车站里的站牌、线路图与报站屏在现有工具里要么是写死的模板、要么只覆盖单一城市风格；本项目把「线网数据」与「物料呈现」解耦，一份数据出全部物料，线网本身也可以在地图上拖放编辑。

## 为什么存在？

- 背景 / 动机：RMG 家族的物料体系成熟，但每种物料都绑定单线、单风格参数，报站屏（放送机）分散在另一个应用里；地图与线网编辑则完全分离。本项目以「一个线网 → 多份物料」为核心重新组织，先从合肥轨道风格落地。

## 如何安装和运行？

- 前置要求：Node 24（见 `.nvmrc`）、vp（Vite+）；线网地图需要联网加载底图瓦片。
- 安装步骤：`vp install`（依赖走 npmmirror，见 `.npmrc`）。
- 运行 / 启动：`vp dev`；检查 `vp check`；测试 `vp test`；构建 `vp build`。部署配置见 `docs/ARCHITECTURE.md#外部系统`。

## 当前状态

- 阶段：原型（可用版本）。
- 已具备：
  - 「线网」工作区：真实地图上的全网线路；拖动站点改坐标，拖到另一站附近可并入成为换乘；「延伸线路」模式点击地图追加站点；新建 / 删除线路；站点改名、调序、删除；换乘列表可一键拆分为独立站；底图可切高德 / 浅色 / OSM / 无。
  - 「车站」工作区：站名牌、线路牌、报幕机三种物料；逐站切换方向与开门侧；PNG / SVG 导出；整线播报文本导出。
- 已知限制：仍无自由绘制线形（线路按站点顺序连直线，不支持曲线与共线走向）；没有撤销栈，只能恢复内置线网；报幕机只输出文字画面，未合成语音；LED 屏的尺寸与排版是通用 PIS 实现，不代表合肥官方标准。

## 核心技术

- 语言 / 框架 / 关键依赖：TypeScript、React 19、Tailwind 3.4 + shadcn/ui、zustand、Leaflet；SVG 物料由 React 组件直接渲染，LED 点阵使用像素字体（Fusion Pixel 12，OFL-1.1）栅格化。
- 站点坐标存 WGS-84，高德底图按 GCJ-02 转换后渲染（`src/lib/coord.ts`）。
- 详细设计与决策见 `docs/`；许可与来源见 `LICENSE` 与 `NOTICE.md`（GPL-3.0-only）。
