# metro

合肥轨道风格的线网与车站物料制作工具：同一份线网数据派生终点站站牌、当前站名牌、路线图与放送机。

## 这是什么？

- 定位：面向地铁爱好者的**物料制作**工具，不依赖服务端，打开网页即可创作与导出。
- 解决的核心问题：地铁车站里的站牌、路线图和报站屏在现有工具里要么是写死的模板、要么只覆盖单一城市风格；本项目把「线网数据」与「物料呈现」解耦，一份数据出全部物料。

## 为什么存在？

- 背景 / 动机：RMG 家族的物料体系成熟，但每种物料都绑定单线、单风格参数，且放送机（LED 点阵报站）分散在另一个应用里；地图与线网编辑则完全分离。本项目以「一个线网 → 多份物料」为核心重新组织，先从合肥轨道风格落地。

## 如何安装和运行？

- 前置要求：Node 24（见 `.nvmrc`）、vp（Vite+）。
- 安装步骤：`vp install`（依赖走 npmmirror，见 `.npmrc`）。
- 运行 / 启动：`vp dev`；检查 `vp check`；测试 `vp test`；构建 `vp build`。部署配置见 `docs/ARCHITECTURE.md#外部系统`。

## 当前状态

- 阶段：原型（首个可用版本）。
- 已知限制：内置线网为合肥 1–8 号线 + S1；尚无地图底图与线网编辑界面；放送机只有文字画面与整线文本导出，未合成语音；LED 屏的尺寸与排版是通用 PIS 实现，不代表合肥官方标准。

## 核心技术

- 语言 / 框架 / 关键依赖：TypeScript、React 19、Tailwind 3.4 + shadcn/ui、zustand；SVG 物料由 React 组件直接渲染，LED 点阵使用像素字体（Fusion Pixel 12，OFL-1.1）栅格化。
- 详细设计与决策见 `docs/`。
